# Vercel MCP server

Review deployments and create an approved Vercel project. Read provider data first, then explicitly approve the selected change with operator write opt-in and a unique per-call approval key.

A direct-provider MCP server with useful local execution. No PipMCP account is required for local use. Provider API access and any provider charges are your responsibility.

## Quick start

Requires Node.js22+. Clone this repository, then run:

```sh
npm ci --ignore-scripts
npm test
npm start
```

The default command inspects the tools offline. Configure your own credentials in your environment:

- `VERCEL_TOKEN`



Credential help: https://openapi.vercel.sh

## Execute a real read

Replace example record IDs with records you are authorized to access.

```sh
npm start -- --call list_projects '{"limit":"10"}'
```

## Use with an MCP client

Launch `node /absolute/path/vercel-mcp/server.mjs` using stdio transport; pass credentials through the client environment. Stdout is reserved for JSON-RPC.

## Tools

| Tool | Effect | Purpose |
| --- | --- | --- |
| list_projects | Read | List projects. |
| list_deployments | Read | List deployments. |
| create_project | Explicit approval required | Create project. |

## Concrete workflow

Review deployments and create an approved Vercel project. Read provider data first, then explicitly approve the selected change with operator write opt-in and a unique per-call approval key.

1. list_projects
2. list_deployments
3. create_project

## Optional writes

Writes are disabled by default. Set CONNECTOR_ALLOW_WRITES=true and supply `_approval: {approved:true,idempotencyKey:"unique-request-id"}` on the specific call. Do not reuse a key for a different request. Uncertain outcomes are never automatically replayed; inspect the provider before another attempt.
